# Albion Лутлогер

Лёгкий лутлогер для Albion Online. Записывает, кто что подобрал и с кого, считает стоимость лута по оценке самой игры и сверяет лут с логом гильдейского сундука.

Это урезанная до одной функции переработка лутлогера из [Statistics Analysis Tool](https://github.com/Triky313/AlbionOnline-StatisticsAnalysis) (разбор протокола Photon взят оттуда). Всё остальное убрано, а захват и обработка пакетов переписаны так, чтобы ничто не тормозило.

## Что нужно

- Windows 10 или новее
- [Npcap](https://npcap.com/#download) (установка с настройками по умолчанию)
- Для `LootLogger.exe` — [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0). Если у вас работал Statistics Analysis Tool, он уже установлен. Если не хотите ничего ставить — скачайте `LootLogger-standalone.exe`.

Запускать от администратора не нужно.

## Как пользоваться

1. Скачайте exe со страницы **Releases** и запустите.
2. При первом запуске программа сама найдёт папку игры (или попросит её указать) — оттуда берутся русские названия предметов.
3. Зайдите в игру. Чтобы программа узнала имя вашего персонажа, смените локацию или перезайдите.
4. Журнал заполняется сам. Каждая сессия автоматически пишется в CSV в папку `Документы\AlbionLootLogger`.

### Сверка с сундуком

1. Вкладка «Сверка с сундуком».
2. В игре откройте логи гильдейского сундука, скопируйте их и нажмите «Вставить из буфера» (можно несколько логов подряд).
3. «Сравнить». Для каждого игрока видно, сколько он залутал, сколько сдал, что не сдал и на какую сумму.

Можно загрузить журналы других лутлогеров (кнопка «Загрузить журналы…» во вкладке журнала) — дубли отбрасываются автоматически. Поддерживается и формат экспорта Statistics Analysis Tool.

### VPN и ExitLag

В режиме «Авто» программа слушает все сетевые адаптеры и сама выбирает тот, где идёт трафик игры. Если данные не идут, во вкладке «Настройки» выберите адаптер VPN/ExitLag вручную и нажмите «Применить».

## Чем отличается от лутлогера в SAT

- Захват в отдельном потоке, фильтр пакетов работает в драйвере — загрузки и стримы не мешают; буфер захвата 16 МБ.
- Поток захвата никогда не ждёт интерфейс: записи передаются в окно пачками раз в 300 мс.
- Повторно отправленные сервером пакеты распознаются по номеру команды Photon и не создают дубли.
- Никаких сетевых запросов, загрузок иконок и фоновых таймеров.

## Сборка

```
dotnet test tests/LootLogger.Tests
dotnet publish src/LootLogger -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```

Каждый push в `main` собирается в GitHub Actions и публикуется в Releases.
